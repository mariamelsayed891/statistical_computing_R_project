# Statistical Computing Project (R)

This repository contains a complete academic project developed for a Statistical Computing course.

## Project Overview
In this project, we worked with a real-world dataset and implemented a full data analysis workflow, including:
- Data import and cleaning (handling missing values, correcting data types, and removing duplicates)
- Exploratory Data Analysis (EDA) using ggplot2
- Data manipulation and descriptive analysis using tidyverse
- Statistical inference procedures
- Linear regression modeling and diagnostic analysis
- Reproducible reporting using Quarto
- Interactive dashboard development using Shiny
- Simulation of the real dataset and comparison with simulated data (bonus)

## Tools & Libraries
- R
- RStudio
- tidyverse
- ggplot2
- Quarto
- Shiny

## How to Run
1. Open the project in RStudio.
2. Install required packages listed in the scripts.
3. Run the Quarto file (.qmd) to reproduce the report.
4. Run the Shiny app (app.R) to view the dashboard.
